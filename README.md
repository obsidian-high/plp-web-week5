# SpendWise JavaScript Foundation

SpendWise is a personal budgeting dashboard designed to help users understand their income, expenses, savings, and remaining balance.

This version of SpendWise introduces JavaScript functionality to the dashboard.

The application collects budgeting information from the user, performs calculations, and displays the results in the browser console.

The financial information displayed on the page is static and is used to demonstrate the JavaScript foundation.
