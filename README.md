# SpendWise JavaScript Foundation

## 1. Project Overview

SpendWise is a personal budgeting and expense-management application designed to help users understand how they are using their money.

The project began as a static dashboard created with HTML and CSS. This version introduces JavaScript to provide the application's first layer of functionality.

The purpose of this assignment is to build the JavaScript foundation of SpendWise by applying fundamental programming concepts such as variables, data types, user input, calculations, functions, conditional statements, and input validation.

At this stage, the application does not store financial information permanently in a database. Instead, it uses JavaScript variables and user input to demonstrate how budgeting information can be collected and processed.

The current version allows a user to enter their monthly budget and total expenses. SpendWise then calculates the user's remaining balance and reports their financial status in the browser console.

---

# 2. Project Objectives

The main objectives of this version of SpendWise are to:

- Introduce JavaScript functionality into the existing dashboard.
- Store budgeting information using variables.
- Collect information directly from the user.
- Convert user input into appropriate data types.
- Perform financial calculations.
- Organize calculations using reusable functions.
- Use conditional statements to interpret calculation results.
- Validate user input before processing it.
- Display understandable results in the browser console.
- Establish a foundation for more advanced functionality in future versions.

The project focuses on JavaScript fundamentals rather than building a complete financial management system.
